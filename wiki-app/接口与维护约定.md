# SCORE 百科接口与维护约定


项目资料、模组源、工具链均由命令行显式指定；源模组只读。当前客户端与内容格式遵循下列契约。

Portable root: SCORE百科.exe, index.html + Vite assets (client), app-manifest.json, config/factions.json, packs/<pack_id>/manifest.json + data/** + assets/images/** (content), active.json {version:1,current:pack_id,previous:pack_id|null}. Content packets immutable. Data update ZIP root manifest.json and only listed JSON/data + local images/fonts; no JS/HTML/CSS/EXE/config. App manifest {format_version:2,app_version:"4.0.0",client_version:2,content_format_version:2,project_id:"SCORE-fa82e2d014",file_hashes:{client paths:sha256}}. Content manifest format_version=2,content_format_version=2,min_client_version=2,project_id same,pack_id safe <=100 chars [A-Za-z0-9_-],batch,files.index='data/index.json',file_hashes excluding own manifest, sizes; existing source factions metadata in factions. pack_id=batch + '-' + sha256(canonical sorted file_hashes JSON UTF8 compact)[:12]. Root config externally mutable, never a hashed content file. active.json never treated as user config.

Index retains existing fields, adds origin (old component/faction key), editorPrefix (normalized effective EditorPrefix string), glossaryPriority number|null; members also origin/editorPrefix/path/audit. Underlying source-qualified identity = origin + Unit:id. Entry paths retain data/entries/<origin>/<id>.json. Player entry navigation adds origin/editorPrefix/glossaryPriority. Authority entry.presentation.glossary_priority is a Fact; preserve all older Fact/sources except explicit addition. Group priority primary, else min members with inferred basis. Categories and technical exclusion unchanged. Existing prefix grouping (within equal prefix) preserved; rendering assignment is config-driven, source routes still distinguish IDs.

Config {version:1,factions:[{id,prefixes:[string],name,defaultVisible:boolean,order:number,branches?:{prefix:label}}]}. 18 factions, all true. Main order Cerberus10,CovertOps20,Junker21,Dominion22,Golden30,HTXL40,Silver41,Ihanrii50,Nerazim51,Moebius60,Primal70,Purifier80,Taldarim90,Hybrid91,Umojan100,Webby110,Deluxe111,Infested112. Alias RCZ=>Cerberus; Golden/Golden F/黄金=>Golden branch Golden F='F'; CovertOps 特战幽灵=>CovertOps branch='特战幽灵'. Prefix normalized trim then leading '-' trim; duplicate comparisons case-insensitive. Unknown=>Unassigned 未归属. Invalid reload retains last valid, startup last-valid/default with visible warning. Preserve user config through updates. Name mapping as user specified (Deluxe德鲁克斯 draft display). Default config generated by data/tool owner; Go validates same contract.

Go APIs all mutation Host + exact Origin + token from health; JSON operations body.token, upload header X-SCORE-Token. Errors JSON {error:string}. GET /manifest.json returns active content manifest plus app_version/client_version (runtime metadata); GET /__app/health retains app/root/identity/token, adds app_version/client_version/batch/pack_id/origin/state. GET /__app/config -> {config,revision,warning,path}; POST /__app/config/reload {token} -> same or422. GET /__content/<pack_id>/<path> only packet manifest-listed content; GET / root and Vite assets only app manifest paths; legacy /units/<origin>/<id>.html redirects to /#faction=<old origin>&source=<origin>&unit=Unit%3A<id> (frontend normalizes assignment).

POST /__app/session {token,client_id} is a streaming NDJSON response, first {event:'hello',pack_id,batch}, then heartbeat15s {event:'heartbeat',...}; activation broadcast {event:'content-changed',pack_id,batch}. Page session retained while React/Other alive, fetch stream aborted on pagehide/unmount, pageshow reconnect. Server counts connections, last gone30s autoquit; no first page300s autoquit; pending install suspends timer. Explicit quit or control window close shared shutdown; cancel precommit update, finish commit before exit. --headless suppress control window for package tests, --no-browser prevents browser open; --idle-grace-seconds/--startup-timeout-seconds supported for deterministic actual-process tests. Native Windows control window always default, status+URL+batch, Open and Exit buttons; repeat process POST /__app/open {token} brings old window forward then opens browser. --no-browser alone still native window unless --headless.

GET /__app/update/status -> {current:{pack_id,batch},previous:{pack_id,batch}|null,busy:boolean,staged:object|null}. POST /__app/update/check application/zip -> {staging_id,pack_id,batch,summary:{entries:number,files:number}}; validates/extracts fresh staging only, does not activate. POST /__app/update/install {token,staging_id} -> {state:'installed',pack_id,batch,previous_pack_id}; POST /__app/update/rollback {token} same state='rolled_back'. ZIP max512MiB,total expanded2GiB,count50000; reject traversal, symlinks, case collisions, duplicates, unsafe executable/client/config paths, wrong project/schema/client, missing/extra files/hash errors. All ops serialize. Pointer atomic replacement and recovery; previous content retained. No network required. No new thirdparty Go dependencies.

React content requests pinned to active pack: prefix /__content/<pack_id>/ onto every JSON and image/font path; cache keyed full versioned URL. On content-changed show update notice and reload current route to new pack, never combine old/new resource state. Keep faction defaults hidden toggle in settings; hidden deep links permitted with notice. New route #faction=<display id>&source=<origin>&unit=Unit:<id>. Old faction-only+unit uses origin for old11 keys, resolves assignment; do not first-match duplicate Unit IDs. Global search includes all visible factions and each form, qualified links. Branch filter replaces old subfaction filter. Settings show app/data versions, state, Reload config, Show hidden factions, evidence toggle.

Other becomes React page #page=other, with content data/other.json, preserving legacy content as structured tables/text/images (data owner parser); no inline HTML scripts included in updates. Frontend owner render safe plain values. Data owner defines other.json concrete shape and messages frontend agent quickly. No static other.html needed beyond root Go redirect /other.html -> /#page=other.

Owners: data worker tools/** + default configuration + other parser + authority generation (root owns builds/release audits/toolchain helper). Frontend worker app/**. Launcher worker launcher/**. Root shared Hub optional Fact validator and integration scripts/release/report. Nobody edits other's owned source; communicate contract changes explicitly. Existing Hub dirty edits unrelated preserved. Agents save stage sources only (except authorized root external generation), no mod/source or confirmed-KB edits. Tests should cover real failure modes, not mirror code.

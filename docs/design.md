# SCORE 星际百科视觉规范

主题以用户提供的灰机合作任务截图为准：舰桥科技纹理、黑色指令面板、游戏图标和金属框，信息密度适合桌面阅读。

色板：深空 #020c18，面板 #00111b，科技线 #164f72，文字 #e4edf2，星灵 #6891ff，人类 #42d043，异虫 #e5a027。生命绿、护盾蓝、能量紫仅用于对应数值。

字体采用系统微软雅黑／Microsoft YaHei、Segoe UI，无在线字体。大标题 48px、分区 28px、正文 17px，名称保持中文直排，说明行宽控制在阅读范围内。

总览：阵营方形头像横排；筛选紧随其下；单位、英雄、建筑、其他以左侧标签和右侧整齐图标分组。详情：左侧介绍与肖像／5×3命令卡，右侧属性表；下方技能与升级双列金属卡。

金属框外层通过多层细线与切角表现，内部为近黑透明面板；纹理使用低对比电路线，不能干扰正文。命令卡每格一个图标，其余候选使用浮层，不能拉高布局。

审查：取消营销导览、CTA、计数仪表盘和通用圆角后台卡片。最有辨识度的元素是原始游戏图标、黑底指令格与种族边框，装饰仅服务于这一主体。主体和所有标签左对齐，不使用加载动画装饰。

无障碍：键盘聚焦边框清晰；气泡可点击及 Escape 关闭；展开内容使用原生 details；默认视图包括 aria/title 都不透露 ID、事实状态或源证据。设置打开后才请求审计数据。

## 导航与离线维护

采用舰桥面板、三族边框、图标密度与原始 5×3 命令卡。18 个语义阵营头像按可编辑配置排序并在桌面换行；跨阵营搜索结果显示阵营和分支，其他卡片不增加调试标签。

设置沿用紧凑金属浮面板，版本、服务状态、显隐与配置重载集中于此。更新页是独立工具页，以版本表、文件选择、校验摘要、安装和回退的顺序展示；校验不自动激活数据。所有按钮有可见禁用状态、错误与进度文本，键盘可使用原生输入和按钮。

词条保持源组件限定的地址身份。资源、图片和证据固定在同一个不可变内容包 URL；切换包时清空内容缓存并取消旧页面请求。坠毁系统改为同一 React 应用内的安全文本与表格，默认隐藏证据列，保留数量和数值表格。
